what I do

Authorized assessments as an independent contractor. Scoped engagements only. Rules of engagement before any work starts.

Social engineering
Authorized tests of people and process — realistic pretext over email, phone, and in person, including help-desk scenarios when they are in scope. Research is used to build the engagement, not offered on its own.
Physical penetration testing
On-site assessments of facilities and access control — what an unauthorized person can reach, and how far that access goes. Alarm, camera, and sensor coverage is documented; defeating it only when the engagement says so.
Technical penetration testing
External and internal networks, including assumed-breach. Active Directory. Cloud (AWS, Azure, GCP). Wireless. API testing outside a full web-app engagement. Mobile applications.
Web application assessment
Unauthenticated and authenticated web applications. Focused work on authentication, session handling, and access control.
